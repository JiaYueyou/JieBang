2. 技术创新性（25分）

JTT 用户端结合知识图谱回查、Agent 工具调用循环与规则降级，保证生成结果可追溯、可拒绝、可复核。

2.1 图谱回查 + 防幻觉机制

AI 助手与学习路径生成的每一条技能断言，均通过 Neo4j 图数据库执行「技能名称模糊匹配 → 标准技能域 → 来源支持关系」三步回查；不满足图谱约束时直接拒绝该声明并给出可观察的原因。20 条案例全部正确响应，正确拒绝率 100.0%。

2.2 Agent 自主工具循环

提供 /api/v1/assistant/agent-chat 接口（120s 超时），LLM 可自主调用：①图谱节点/扩展/搜索 ②岗位原文检索 ③技能差距分析 ④学习资源生成 四类工具，返回 reply、thinkingSteps、toolsCalled、followUpQuestions 四段结构化输出。

2.3 简历 → 匹配 → 学习路径 闭环

简历解析出的技能集合与岗位必备技能集合作差得出「能力差距」，学习路径 AI 生成仅围绕差距生成步骤，学习资源推荐再次过滤与岗位无关材料，避免用户被无效规划干扰。

2.4 短语润色四风格

optimize-phrase 支持 professional（专业表达）/ concise（简洁有力）/ match（向岗位靠齐）/ impact（成果量化）四种风格，返回多条候选建议；当 LLM 不可用时走规则降级。

在此处补充「Agent 工具调用链截图 / 图谱回查结果示例截图 / 短语润色前后对比示例」，或一段实际对话示例（含 thinkingSteps 与 toolsCalled 展示）。

3. 用户体验（15分）

JTT 用户端前端为 Vue 3 + TS + Vite，使用 Element Plus + Plus Jakarta Sans 字体，移动端侧栏自适应。浏览器交互已覆盖主要页面。

页面清单

  • 登录 / 注册页
  • 首页 / 岗位列表（关键词、城市筛选）
  • 岗位详情（含 JD 原文 + 岗位技能图谱）
  • 简历列表 / 新建 / 编辑 / 复制
  • 简历上传解析（DOCX / PDF 拖拽）
  • 人岗匹配结果（匹配度 + 已匹配技能 + 能力差距）
  • 学习路径（AI 生成 / 手动编辑 / 资源推荐）
  • AI 助手全局浮窗（聊天 + 短语润色）
  • 收藏夹（岗位 / 学习路径分类）
  • 个人资料 & 密码修改

交互亮点

  • 匹配详情逐项展开「简历原文证据 / 岗位 JD 原文证据」
  • AI 助手显示 LLM 思考步骤（thinkingSteps）与工具调用（toolsCalled）
  • 短语润色支持「一键采纳建议」替换简历段落
  • 学习路径每一步包含资源卡片、时长、平台与类型
  • 移动端响应式布局：768px 以下自动折叠侧栏
