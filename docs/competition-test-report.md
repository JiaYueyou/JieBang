技术链路包含大模型编排、知识图谱、RAG 检索与证据约束。部署环境采用可离线复现的 `local_deterministic / signed-token-hash-v1 / 256维` 嵌入与 `local_hash` 索引，覆盖 529 条证据、37 个标准岗位、44 项技能和 8 个来源平台。
