# 历史岗位基线 v2

> 文档类型：现行专项说明
> 状态：已实现首版
> 核验日期：2026-08-12（`c995a09e`）

## 目标

建立一个冻结、可追溯且可复算的历史岗位基线，用于区分成熟技能、需求增长
和已确认的新兴技能。历史网页或一次性爬虫快照不得直接改写已发布基线。

## 数据准入

每条历史岗位必须保留以下字段：

| 字段 | 用途 |
| --- | --- |
| `posted_at` | 唯一用于趋势时间轴的原始发布时间 |
| `archived_at` | 网页存档快照时间，仅作为存在性佐证 |
| `collected_at` | 本系统采集时间，不参与趋势计算 |
| `url` / `archive_url` | 原始页面与存档页面证据 |
| `source` / `source_type` | 平台与来源类型 |
| `license_note` | 授权、公开用途或人工确认记录 |

来源优先级为：企业官方招聘站、公共就业服务平台、获得许可的商业平台数据、
网页存档。网页存档只能补足原始页面证据，不能把存档日期误当职位发布时间。

## 基线版本

首个建议版本为 `baseline_2025H2_v1`，统计区间为 2025-07-01 至
2025-12-31。发布前必须通过：

- 至少 3 个完整自然月；
- 至少 500 个去重岗位簇；
- 至少 3 个来源平台，且单一来源不得主导结论；
- 仅使用质量合格、未排除且有发布时间的岗位；
- 技能事实须为已确认事实，或经人工抽样审核后明确纳入基线。

每次发布记录版本、时间范围、来源构成、去重规则、技能抽取规则、样本量和
数据校验结果；发布后只能新建版本，不能就地覆盖。

## 新兴技能发布门槛

统计单位为去重的“企业 × 标准岗位 × 城市 × 周”岗位簇。只比较同一岗位族、
区域和职级中的技能渗透率，而不比较原始事实行数。

候选技能必须同时满足：

- 历史基线中未出现或渗透率极低；
- 当前 28 个完整自然日内至少 10 个岗位簇；
- 覆盖至少 3 家企业、2 个来源平台和 2 个时间桶；
- 相对基线提升至少 50%，绝对渗透率提升至少 2 个百分点；
- 通过置信区间检验或人工审核。

未满足多源和持续性条件的条目仅标记为“单源新增候选”，不出现在正式新兴技能
列表。Java、Spring、MySQL 等历史成熟技能只能进入“需求变化”视图；软技能
默认进入通用能力趋势，不进入技术新兴榜。

## 当前过渡策略

在冻结历史基线发布前，趋势接口要求至少 20 条当前已确认技能事实、12 条历史
已确认技能事实和 2 个历史独立来源。任一条件不满足时，接口返回
`insufficient_data=true` 且不发布新兴技能结论。
